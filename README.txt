EasyRecord - a simple, free screen recorder
https://github.com/tbrains1998-web/easyrecord

USE IT
 1. Pick Full Screen, One Window, or Drag a Box.
 2. Slide Quality (higher = sharper video, bigger file).
 3. Press Record, or F12 from anywhere. Press Record or F12 again to stop;
    the video saves by itself. F9 = pause / carry on, F11 = screenshot.
 4. Videos go to the Videos folder in your user folder
    (%USERPROFILE%\Videos\EasyRecord), or to a folder you pick in the app.

MAKE THE APP YOURSELF (only if you downloaded the source, not the installer)
 1. Install Python from https://www.python.org/downloads/
    (tick "Add python.exe to PATH").
 2. Download the project from the GitHub page above
    (Code > Download ZIP, then unzip).
 3. Double-click build.bat. Wait a few minutes.
 4. Your app is dist\EasyRecord.exe. Copy it anywhere and double-click it.
